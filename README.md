# Gentle Momentum (my.GOALs)

Habit and goal tracking app, copied out of Lovable so it can be built on without Lovable credits.

## Run it

```sh
npm i
npm run dev
```

## Status

- Backend (Supabase accounts, tables, row-level security): done and live.
- Theme and helpers (`src/styles.css`, `src/lib/`): done.
- Screens: **not built yet.** `src/routes/index.tsx` is still Lovable's blank placeholder.
- UI components (`src/components/ui/`) are the standard shadcn set. Regenerate them with
  `npx shadcn@latest add --all` (config is in `components.json`).

## Built with

TanStack Start, TypeScript, React, Tailwind CSS, Supabase
